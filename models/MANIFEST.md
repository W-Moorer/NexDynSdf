# Model catalog and provenance

This directory consolidates all persisted model assets found in the reviewed
source asset locations, not only the small regression subset used initially.
The catalog contains 34 assets totaling about 16.4 MB:

| Directory | Assets | Purpose |
|---|---:|---|
| `pycoco/obj_library/` | 9 OBJ | original PyCoCo library meshes |
| `pycoco/obj_model/` | 15 OBJ | smooth, nonsmooth, compound, cam, gear, and slideway models |
| `nagata/` | 3 NSM + 1 ENG | core corner-normal models and cone crease cache |
| `sdfmodel/` | 4 NSM + 1 STL | generated cam/gear and validation models |
| `sdflib/` | 1 OBJ | third-party Gear benchmark model |

`pycoco/`, `nagata/`, and `sdfmodel/` are prior work authored by the
NexDynSdf repository owner and require no separate model license. Only
`sdflib/Gear.obj` is third-party; its SdfLib MIT text is retained at
`licenses/SdfLib-LICENSE.txt`.

## Machine-readable records

- `CATALOG.tsv` records every asset's source project, exact revision, tracked
  or local/generated state, original path, ownership, format, byte count, and
  SHA-256. `scripts/update_model_catalog.ps1` verifies every repository copy
  against its source file before regenerating the table.
- `AUDIT.tsv` is generated by `nexsdfmodelaudit` through the production OBJ/NSM
  loaders and topology code. All 32 OBJ/NSM assets parse. Twenty-nine pass the
  current strict signed-distance requirement after duplicate-coordinate
  welding and outward orientation. `scripts/update_model_audit.ps1` regenerates
  this report as canonical UTF-8/LF text.

The three parsed but not runtime-ready models are retained deliberately:

| File | Current limitation |
|---|---|
| `pycoco/obj_model/complex_geometry/SlidewayRotatingModel.obj` | two closed connected components; one `.nsdf` currently accepts one component |
| `sdfmodel/cam.nsm` | boundary and non-manifold edges in the generated experimental NSM |
| `sdfmodel/gear.nsm` | boundary and non-manifold edges in the generated experimental NSM |

The closed `PressureLubricatedCam.obj` is runtime-ready and is the recommended
current cam input. `sdfmodel/cam.stl` is preserved as source evidence but STL
is not currently a NexDynSdf input format. `nagata/cone.eng` is an Enhanced
Nagata crease/cache payload paired with `cone.nsm`, not an independent mesh.

## Scope and exclusions

Included source locations are PyCoCoFastSDF's `obj_library/` and `obj_model/`,
enhanced-nagata-sdf's `models/`, SDFmodel's persisted generated cam/gear and
validation assets, and SdfLib's `models/Gear.obj`.

Excluded are compiler object files named `.obj`, dependency/test meshes inside
SdfLib build trees, generated SDF serialization/results, and derived
`outputs/*_iso.obj` surfaces. These are build products or reconstructed output,
not source model assets. The identical Gear OBJ present in PyCoCoFastSDF and
SdfLib is retained under both source namespaces; `CATALOG.tsv` exposes their
matching hash instead of silently discarding either provenance path.
